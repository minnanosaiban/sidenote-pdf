# sidenote-pdf

🔗 https://sidenote-pdf.pages.dev/

## このアプリについて

- 文章やスクリーンショットの資料に、右側のサイドノートで注釈を付けていくアプリです。
- 左＝本文（テキスト・画像）、右＝サイドノート、の2カラム構成です。
- **本文の書式編集（インデント等）は持たない、注釈専用のシンプル版です。** 自分で文書を組み立てながら注釈も残したい場合は [sidenote-pdf-doc](https://github.com/minnanosaiban/sidenote-pdf-doc)（文書作成＋サイドノート版）を使ってください。
- **処理はすべてブラウザ内で完結し、内容はサーバーに送信されません。**
- 注釈済みの範囲は編集できなくなるため、元の文章を誤って書き換える心配がありません。
- 公開は Cloudflare Pages を利用しています。

## 使い方

1. 左側に本文となる文章を貼り付ける（スクリーンショットは Ctrl+V での貼り付け、または段落にカーソルを乗せて出る「＋画像」から挿入）
2. 注釈したい一文・画像を選択すると入力欄が出るので、コメントを書いて色（自分／共有相手／重要）を選ぶ
3. 同じ範囲に複数人でやり取りしたい場合は、サイドノートの「＋ 返信」で追記できる（返信スレッド）
4. 段落・画像はJIMDOのようなブロック単位の操作で、段落にカーソルを乗せると出る「×」でその1ブロックだけ削除できる
5. 作業内容はブラウザに自動保存される。日をまたいで再開する場合は「続きから再開」
6. 区切りの良いところで「保存」（.jsonファイルに書き出す。画像も内包した1ファイル。共有相手はこのファイルを「開く」で開いて注釈を追記できる）
7. 印刷・共有用には「PDF化」（印刷ダイアログが開くので、保存先で「PDFに保存」を選ぶ）

## 仕組み（ブラウザ完結）

- 本文は`contenteditable`の段落（`.para`）単位で管理し、注釈した範囲は`contenteditable="false"`にしてロックします（原文の改変防止）。段落・画像それぞれにカーソルを乗せると「＋画像」「×削除」が出る、ブロック単位の操作にしています（グローバルな挿入・全消去ボタンは持たせていません）。
- 1つの注釈範囲（アンカー）には複数のノートを配列で持たせており、返信スレッドとして追記できます。色は黒＝自分／青＝共有相手／赤＝重要の3色です。
- 保存（.json）はタイトル＋日時付きファイルに書き出します。画像はdata URLとして内包するため1ファイルで完結します。あわせてlocalStorageへの自動保存もあり、次回起動時に「続きから再開」で復元できます。
- 保存（.pdf）は独自のPDF生成ライブラリを使わず、ブラウザ標準の印刷機能（印刷用CSS＋`window.print()`）を利用します。サイドノートは段落の隣にfloatで配置し、ページをまたぐレイアウトにも対応します。
- 本文は1行37字を目安に折り返します（CJKフォントの全角1文字≒1emという近似です）。
- React / Next.js は使用していません（素のHTML＋バニラJSで実装しています）。
- アイコンは Bootstrap Icons（MIT License）から使う分だけSVGをそのまま埋め込んでいます。CDN・Webフォントは不使用です。詳細は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。

## ファイル形式の使い分け

- **.json**：作業の続きの保存・共有相手とのやり取り用（双方向。相手も「開く」で開いてノートを追記できます）
- **.pdf**：印刷用、またはjsonでのやり取りに不慣れな相手向け

## ローカルで動かす

```bash
npm install          # wrangler を入れる
npm run dev           # http://localhost:8788 で確認
```
`python -m http.server -d public 8000` でも構いません。

## 公開（Cloudflare Pages）

```bash
npm run deploy       # wrangler pages deploy
```
本人・関係者限定にする場合は、Cloudflare Access（Google ログイン）を前段に設定してください。

## 運用上の注意

- `local-test/`（プロトタイプ・動作確認用ファイル）は `.gitignore` で除外済みです。
- 保存した`.json`（画像を内包）には、注釈対象の資料そのものが含まれます。**個人情報・機微情報を含むファイルはコミット・pushしないでください。**
